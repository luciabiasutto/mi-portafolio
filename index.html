Plataforma Digital para la Localización de Puntos de Donación

Demo del proyecto

Descripción

El proyecto tuvo como propósito desarrollar una plataforma digital que permitiera localizar puntos de donación y reciclaje en la ciudad, brindando a los usuarios la posibilidad de identificar fácilmente los lugares más cercanos donde realizar aportes solidarios o sustentables.

La iniciativa surgió ante la falta de información centralizada y accesible sobre centros de recolección, situación que dificultaba la participación ciudadana en acciones solidarias y ambientales.

Tecnologías utilizadas

Backend Java Spring Boot
Frontend React
Base de datos MySQL
Geolocalización Leaflet
Metodología Scrum

Características principales

  • Visualización de puntos de donación y reciclaje en mapa interactivo
  • Sistema de filtrado por tipo de donación y ubicación
  • Gestión eficiente de puntos de donación
  • Integración de información de distintas organizaciones
  • Interfaz intuitiva para facilitar la participación ciudadana
